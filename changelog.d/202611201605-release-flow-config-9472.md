### Added
- (release) **`release-flow.json` and `docs/RELEASE_CHECKLIST.md`, so TokenSave Manager's Release Wizard can check and tag a release.** The file names the project's own check scripts, the three files a release must carry and the tag message; the checklist is the by-hand installer list (install-folder page, Make New Folder, Start menu, repair/uninstall prompts, project-file double-click, Save/Save As, Controlled Folder Access) the Wizard shows and remembers per tag. No workflow or build change; the Wizard only reads, plans and, on a click, runs the tag commands, and never publishes. (`release-flow.json`, `docs/RELEASE_CHECKLIST.md`, `docs/RELEASING.md`, `docs/RELEASE_CONTENTS.md`)
