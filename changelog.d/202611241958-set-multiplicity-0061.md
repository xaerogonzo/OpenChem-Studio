### A molecule's spin multiplicity can be set and is kept
- **The Quantum Chemistry panel's Multiplicity box now remembers what you set for that molecule** (saved with the project, undoable). Before, selecting a molecule reset it to what the drawing implies, so a singlet O2 or a triplet carbene had to be re-entered every time. A value equal to the drawing's own clears the setting; a value the structure's electrons cannot have is not stored (Run still refuses it with the reason), and a stored value that a later edit makes impossible is ignored. The choice also decides which methylene geometry the open-shell table builds (singlet 102.4 degrees, triplet 133.9).
