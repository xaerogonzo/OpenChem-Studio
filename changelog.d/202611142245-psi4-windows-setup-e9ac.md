### Psi4 Set Up downloads the pinned Windows installer

- On Windows, External Tools > Psi4 offers Set Up Automatically: it fetches the Psi4conda 1.11 installer from the project's Georgia Tech host (URL, size and SHA-256 pinned after a live hash), silent-installs it into the app's tools folder, and points the path at `Scripts\psi4.exe`. Test still runs the two-atom job.
