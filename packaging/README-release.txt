OpenChem Studio
===============

Run OpenChemStudio.exe to start the program. Press F1 anywhere for the built-in
Help; it is part of the program and needs no files from this folder.

  Documentation, release notes, issue tracker and source code:
  https://github.com/xaerogonzo/OpenChem-Studio

Your projects, settings and downloaded tools are NOT stored in this folder, so
deleting or replacing the folder never loses them. (Settings > External tools
shows where the data folder is.)

What is in this folder
  OpenChemStudio.exe   the program
  _internal\           the runtime and the program's own data; do not edit
  plugins\             plugins, as source; add your own here
  LICENSE              GPL-3.0-or-later; a copy must travel with the program
  CITATION.cff         how to cite OpenChem Studio

The program is not code-signed yet, so Windows SmartScreen may say "unknown
publisher" the first time: choose More info, then Run anyway.
